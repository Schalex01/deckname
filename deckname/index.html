Ersetzt Personen, Firmen, Adressen und Nummern durch Platzhalter, bevor ein Text in ein KI-Werkzeug geht, und setzt sie in der Antwort wieder ein. Alles passiert in Ihrem Browser, kein Server sieht den Text. Die Vorschau prüfen Sie trotzdem selbst: Deckname schützt Namen, es macht einen Text nicht unkenntlich.

Wörterbuch

Jede Karte ist ein Platzhalter. Alle Schreibweisen darauf werden im Text zu ihm, und im Rückweg wird er zu dem, was bei „zurück zu“ steht.

Mehr dazu

Was hier steht, behält seinen Platzhalter, auch nächste Woche im dritten Text. Von Hand Markiertes kommt sofort hinein, Vermutungen erst, wenn Sie den geschützten Text kopieren oder eine Datei herunterladen. Mailadressen, Telefonnummern, IBANs und Kartennummern nie.

Kurzformen und andere Schreibweisen tippen Sie unten auf der Karte ein. Steht eine Schreibweise schon auf einer anderen Karte, schlägt Deckname die Karte vor: ein Klick nimmt sie mit allen Schreibweisen auf, ihr alter Platzhalter bleibt im Rückweg auflösbar. Gestrichelte Chips gehören zu so einer aufgenommenen Karte, das × macht daraus wieder eine eigene.

Entfernt, bleibt im Klartext
Wo das Wörterbuch liegt. Nur in diesem Browser auf diesem Gerät, nicht auf einem Server. Es überlebt Schließen und Neustart. Weg ist es, wenn Sie die Website-Daten löschen, ein privates Fenster oder ein anderes Gerät benutzen. Safari löscht es außerdem nach sieben Tagen ohne Besuch der Seite. Wer es länger braucht: exportieren und die Datei behalten. Der Export enthält Klarnamen.
